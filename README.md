# Mi Garaje

Mi Garaje es una aplicación web móvil de código libre para gestionar ITV, mantenimientos, gastos y vencimientos de vehículos.

Está pensada para uso personal y privado, especialmente para instalarse en un NAS Synology mediante Docker Compose.

## Funciones previstas

- Registro de vehículos
- Historial de mantenimientos
- Control de ITV
- Avisos de próximos vencimientos
- Estadísticas de gastos
- Base de datos SQLite
- Diseño pensado para móvil
- Despliegue en Synology con Docker Compose

## Tecnologías previstas

- React
- Vite
- Tailwind CSS
- Node.js
- Express
- SQLite
- Recharts
- Docker Compose
